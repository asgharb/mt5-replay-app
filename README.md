# راهنمای کامل نصب و استفاده از شبیه‌ساز معاملات

این برنامه یک چارت و شبیه‌ساز معاملات است که روی کامپیوتر خودتان اجرا می‌شود. با آن می‌توانید فایل‌های کندل را ببینید، بازار گذشته را قدم‌به‌قدم مرور کنید، معاملهٔ آزمایشی باز کنید و نتیجهٔ معاملات را بررسی کنید.

این راهنما برای ویندوز و برای کسی نوشته شده که با برنامه‌نویسی، Node.js یا ترمینال آشنایی ندارد. لازم نیست کد بنویسید؛ کافی است مراحل را به‌ترتیب انجام دهید.

## خیلی ساده: Node.js و npm چه هستند؟

- **Node.js** برنامه‌ای است که امکان اجرای این پروژه را روی کامپیوتر فراهم می‌کند؛ مثل موتوری که برنامه برای روشن‌شدن به آن نیاز دارد.
- **npm** همراه Node.js نصب می‌شود و قطعات موردنیاز پروژه را دریافت و آماده می‌کند.
- **PowerShell / ترمینال** پنجره‌ای برای نوشتن دستورهای کوتاه است. در این راهنما فقط دو دستور اصلی را در آن می‌نویسید.
- **`localhost:3000`** نشانی همین برنامه روی کامپیوتر شماست؛ سایت عمومی اینترنتی نیست.

## بخش اول: نصب Node.js

۱. به [صفحهٔ رسمی دریافت Node.js](https://nodejs.org/en/download/) بروید.

۲. نسخه‌ای را انتخاب کنید که کنار آن **LTS** نوشته شده باشد. LTS نسخهٔ پایدار و مناسب استفادهٔ معمولی است. برای کامپیوترهای معمولی ویندوز، فایل **Windows Installer (.msi)** را دریافت کنید.

۳. فایل دانلودشده را باز کنید. در پنجره‌های نصب، گزینه‌های پیش‌فرض را تغییر ندهید و چند بار **Next** و سپس **Install** را بزنید. اگر ویندوز اجازه خواست، نصب را تأیید کنید.

۴. بعد از پایان نصب، پنجره‌های PowerShell یا ترمینالی را که از قبل باز بوده ببندید. پنجرهٔ تازه‌ای را طبق بخش بعد باز کنید.

> این پروژه به Node.js نسخهٔ ۲۰٫۹ یا بالاتر نیاز دارد. انتخاب نسخهٔ LTS از سایت رسمی، معمولاً ساده‌ترین گزینه است.

## بخش دوم: بازکردن پوشهٔ پروژه و اجرای برنامه

اگر پروژه را به شکل یک فایل فشرده با پسوند `.zip` دریافت کرده‌اید، ابتدا روی آن راست‌کلیک کنید و **Extract All / استخراج همه** را بزنید. برنامه را از داخل فایل ZIP اجرا نکنید. پوشهٔ استخراج‌شده را روی کامپیوتر نگه دارید و همیشه تمام پوشهٔ پروژه را جابه‌جا کنید؛ فایل‌های داخل آن به هم وابسته‌اند.

### بار اول: آماده‌کردن پروژه

۱. در File Explorer ویندوز، پوشهٔ پروژه را پیدا کنید؛ پوشه‌ای که داخلش فایل‌هایی مانند `package.json` و پوشه‌های `src` و `public` قرار دارند.

۲. داخل همین پوشه، روی فضای خالی راست‌کلیک کنید و **Open in Terminal** را بزنید. در بعضی نسخه‌های ویندوز این گزینه داخل **Show more options** است. با این کار پنجرهٔ PowerShell یا Terminal در مسیر درست باز می‌شود.

۳. این دستور را کپی کنید، داخل پنجره راست‌کلیک یا Paste کنید و Enter بزنید:

```powershell
npm install
```

این مرحله قطعات لازم برنامه را دریافت می‌کند و ممکن است چند دقیقه طول بکشد. برای این مرحله اتصال اینترنت لازم است. آن را فقط بار اول اجرا کنید؛ مگر اینکه پوشهٔ پروژه را تازه دریافت کرده باشید یا وابستگی‌های پروژه تغییر کرده باشند.

### هر بار که می‌خواهید برنامه را باز کنید

۱. دوباره Terminal را از داخل پوشهٔ اصلی پروژه باز کنید.

۲. این دستور را بنویسید و Enter بزنید:

```powershell
npm run dev
```

۳. پنجرهٔ Terminal را باز نگه دارید. چند لحظه صبر کنید تا پیامی شبیه `Local: http://localhost:3000` دیده شود.

۴. مرورگر اینترنت را باز کنید و نشانی `http://localhost:3000` را در نوار بالای مرورگر وارد کنید.

اگر پیام برنامه نشانی دیگری مثل `http://localhost:3001` نشان داد، همان نشانی را در مرورگر باز کنید.

### بستن برنامه

برای بستن برنامه، به پنجرهٔ Terminal برگردید و کلیدهای **Ctrl** و **C** را هم‌زمان فشار دهید. بعد می‌توانید پنجره را ببندید. تا وقتی Terminal بسته یا متوقف نشده، برنامه در مرورگر در دسترس است.

## بخش سوم: قراردادن فایل‌های دادهٔ بازار

فایل‌های CSV کندل‌ها باید داخل پوشهٔ `public\data` باشند. برای هر نماد، یک پوشهٔ جدا بسازید. نام پوشه همان نمادی است که در فهرست انتخاب نماد چارت دیده می‌شود.

ساختار نمونه:

```text
public
└── data
    ├── DJIUSD
    │   ├── export_DJIUSD._M1_last_48_months_unixms.csv
    │   ├── export_DJIUSD._M5_last_48_months_unixms.csv
    │   ├── export_DJIUSD._M15_last_48_months_unixms.csv
    │   ├── export_DJIUSD._H1_last_48_months_unixms.csv
    │   └── export_DJIUSD._H4_last_48_months_unixms.csv
    ├── XAUUSD
    │   ├── export_XAUUSD._M1_last_48_months_unixms.csv
    │   └── export_XAUUSD._M5_last_48_months_unixms.csv
    └── NDX
        └── export_NDX._M5_last_48_months_unixms.csv
```

### افزودن نماد جدید با File Explorer

۱. وارد `public`، سپس `data` شوید.

۲. برای نماد جدید یک پوشه بسازید؛ مثلاً `XAUUSD` یا `NDX`.

۳. فایل‌های CSV آن نماد را داخل همان پوشه کپی کنید.

۴. نام هر فایل باید تایم‌فریم آن را مشخص کند: `M1`، `M5`، `M15`، `H1` یا `H4`. نام فعلی فایل‌های شما مانند `export_DJIUSD._M5_last_48_months_unixms.csv` قابل‌شناسایی است. لازم نیست بخش ابتدایی نام دقیقاً با یک الگوی خاص ثابت باشد، اما تایم‌فریم باید در نام فایل مشخص باشد.

۵. اگر برای یک نماد و یک تایم‌فریم چند فایل دارید، برنامه فایلی را انتخاب می‌کند که تاریخ «آخرین تغییر» آن جدیدتر است. بنابراین فایل به‌روزشده را داخل پوشه کپی کنید.

۶. اگر برنامه باز است، صفحهٔ مرورگر را یک‌بار Refresh کنید تا پوشه‌ها و فایل‌های تازه پیدا شوند.

### ستون‌های موردنیاز CSV

برنامه فایل‌هایی را می‌خواند که در ردیف اول نام ستون‌ها و در ردیف‌های بعد اطلاعات کندل‌ها باشد. قالب پیشنهادی:

```csv
time,open,high,low,close,tick_volume,spread
1770000000000,62350.1,62380.2,62320.5,62370.4,1250,12
```

این ستون‌ها لازم‌اند:

- `time`: زمان کندل؛ می‌تواند زمان Unix برحسب ثانیه یا میلی‌ثانیه باشد، یا تاریخ و ساعت در یک ستون.
- `open`: قیمت بازشدن کندل.
- `high`: بالاترین قیمت کندل.
- `low`: پایین‌ترین قیمت کندل.
- `close`: قیمت بسته‌شدن کندل.

این دو ستون اختیاری‌اند:

- `tick_volume`: تعداد تیک‌ها یا حجم ثبت‌شده. نبودنش مشکلی ایجاد نمی‌کند.
- `spread`: اسپرد کندل. اگر این ستون نباشد، اسپرد صفر در نظر گرفته می‌شود.

برنامه نام‌های متداول MetaTrader مانند `<TIME>`، `<OPEN>`، `<HIGH>`، `<LOW>`، `<CLOSE>` و `<TICKVOL>` را هم می‌شناسد. فایل می‌تواند با جداکنندهٔ کاما یا Tab باشد. داده‌های زمان تکراری حذف می‌شوند و کندل‌ها بر اساس زمان مرتب می‌شوند.

> اگر فایل CSV شما تاریخ و ساعت را در دو ستون جداگانه دارد، ابتدا مطمئن شوید که قالب آن با برنامه سازگار است؛ برنامه در حال حاضر تاریخ و ساعت را از یک ستون زمان می‌خواند.

### اگر چارت خالی بود

این موارد را بررسی کنید:

۱. فایل‌ها واقعاً داخل پوشهٔ همان نماد باشند؛ نه مستقیماً داخل `public\data`.

۲. پسوند فایل `.csv` باشد.

۳. بخشی از نام فایل تایم‌فریم را نشان دهد؛ مانند `_M5_` یا `_H1_`.

۴. فایل ستون‌های زمان و OHLC را داشته باشد. OHLC یعنی قیمت بازشدن، بالاترین، پایین‌ترین و بسته‌شدن کندل.

۵. پس از کپی فایل‌ها، صفحه را Refresh کنید. اگر باز هم خالی بود، Terminal را بررسی کنید؛ پیام خطا معمولاً می‌گوید کدام فایل پیدا یا خوانده نشده است.

## بخش چهارم: انتخاب نماد و تایم‌فریم

- از فهرست نماد کنار دکمه‌های تایم‌فریم، نماد دلخواه را انتخاب کنید.
- با انتخاب نماد دیگر، برنامه داده‌های آن پوشه را بارگذاری می‌کند و چارت به آخرین دادهٔ آن برمی‌گردد.
- دکمه‌های `M1`، `M5`، `M15`، `H1` و `H4` فاصلهٔ زمانی هر کندل را عوض می‌کنند. برای مثال، در `M5` هر کندل ۵ دقیقه از بازار را نشان می‌دهد.
- انتخاب نماد و تایم‌فریم، نمودار شبیه‌سازی را تنظیم می‌کند. فایل‌های کندل از پوشه‌های محلی پروژه خوانده می‌شوند.

## بخش پنجم: کار با Replay و بک‌تست

**Replay** یعنی دیدن داده‌های گذشته به‌ترتیب زمان، انگار بازار در حال جلو رفتن است.

۱. با کلیک روی **Replay** خط زرد انتخاب نقطهٔ شروع ظاهر می‌شود.

۲. خط زرد را با ماوس به زمان موردنظر در گذشته بکشید. اگر لازم شد، چارت را به عقب حرکت دهید.

۳. روی نقطهٔ انتخاب‌شده دابل‌کلیک کنید تا زمان شروع انتخاب شود. در این مرحله پخش خودکار شروع نمی‌شود.

۴. برای شروع، **Play** را بزنید. با **Pause** مکث می‌کنید و دوباره با **Play** ادامه می‌دهید.

۵. دکمه‌های **Prev** و **Next** یک کندل به عقب یا جلو می‌روند.

۶. از فهرست سرعت می‌توانید سرعت پخش را تغییر دهید. گزینهٔ **Real time** فاصلهٔ واقعی تایم‌فریم را رعایت می‌کند؛ مثلاً در تایم‌فریم یک‌دقیقه‌ای، یک کندل در یک دقیقه جلو می‌رود.

۷. با **خروج از بک‌تست** به آخرین دادهٔ نماد برمی‌گردید.

## بخش ششم: شبیه‌سازی معامله

تنظیمات حساب، سفارش‌ها، تاریخچه و گزارش در پایین صفحه و زیر چارت هستند. اگر دیده نمی‌شوند، صفحه را به پایین اسکرول کنید.

- سرمایهٔ اولیه و تنظیمات حساب را در پنل شبیه‌ساز مشخص کنید.
- حجم پیش‌فرض معامله `0.01` لات است؛ می‌توانید آن را تغییر دهید.
- برای بازکردن معامله، ابتدا وارد حالت Replay شوید و به نقطهٔ زمانی موردنظر برسید؛ سپس **خرید / Buy** یا **فروش / Sell** را بزنید.
- حدضرر و حدسود را هنگام بازکردن معامله تعیین کنید. برای معاملهٔ باز، می‌توانید مقدارشان را در جدول پایین صفحه ویرایش کنید. خطوط مربوط به معاملات باز روی چارت نیز قابل جابه‌جایی‌اند.
- برای سفارش شرطی، نوع سفارش و قیمت ورود را در بخش سفارش‌های شرطی وارد و ثبت کنید.
- سود و زیان شناور مربوط به معاملات باز است؛ مقدار نهایی معامله پس از بسته‌شدن محاسبه می‌شود.

این برنامه شبیه‌ساز است و به حساب واقعی کارگزاری وصل نیست. عبور قیمت فقط از روی کندل‌های فایل انجام می‌شود؛ لغزش قیمت، سوآپ و اجرای جزئی سفارش‌ها در این نسخه شبیه‌سازی نمی‌شوند.

## بخش هفتم: گزارش عملکرد و جست‌وجوی تاریخچه

گزارش عملکرد برای **نماد انتخاب‌شده** و بر پایهٔ معاملات بسته‌شده نمایش داده می‌شود. در آن می‌توانید مواردی مانند سود و زیان خالص، نرخ برد، تعداد برد و باخت، Profit Factor، امید ریاضی، میانگین معاملات سودده و زیان‌ده، بهترین و بدترین معامله، بازده، بیشترین افت سرمایه و منحنی سرمایه را ببینید.

گزارش از سود و زیان تحقق‌یافته استفاده می‌کند؛ بنابراین سود شناور معامله‌های باز در منحنی و آمار این گزارش وارد نشده است.

در بخش تاریخچه می‌توانید:

- با شمارهٔ معامله یا نوع آن جست‌وجو کنید.
- فقط معاملات خرید یا فقط معاملات فروش را ببینید.
- نتیجه را به سودده، زیان‌ده یا سر به سر محدود کنید.
- تاریخ شروع و پایان را انتخاب کنید.
- با دکمهٔ **پاک کردن فیلترها** به نمایش همهٔ معاملات برگردید.

## بخش هشتم: ابزارهای چارت

- نوار ابزار بالای چارت، ابزار نشانگر، خط عمودی، خط افقی، خط مورب، مستطیل و فیبوناچی را دارد. ابزار را انتخاب کنید و روی چارت بکشید.
- برای تغییر رنگ یا حذف یک ترسیم، روی آن دابل‌کلیک کنید.
- برای تنظیم رنگ کندل‌های صعودی و نزولی یا روشن و خاموش‌کردن Grid و Trade History، روی خود چارت راست‌کلیک کنید.
- نمایش سشن نیویورک اختیاری است. با فعال‌کردنش می‌توانید حالت خودکار یا تنظیم دستی زمان و اختلاف ساعت بروکر را انتخاب کنید.

## بخش نهم: آرشیو بک‌تست

برنامه هنگام اجرای بک‌تست، وضعیت آن را در حافظهٔ همان مرورگر ذخیره می‌کند. برای ادامه‌دادن، پنل آرشیو را باز کنید و **ادامه** را برای آرشیو موردنظر بزنید. آرشیو به نماد مربوط به خودش وابسته است؛ اگر پیام داد نماد دیگری انتخاب شده، همان نماد را از فهرست بالای چارت انتخاب کنید.

- **خروجی JSON** یک فایل پشتیبان از آرشیو می‌سازد. فایل JSON را در جای امنی نگه دارید تا بتوانید بعداً آن را وارد کنید یا به کامپیوتر دیگری ببرید.
- **ورودی JSON** آرشیوی را که قبلاً از برنامه خروجی گرفته‌اید، اضافه می‌کند.
- با **حذف** می‌توانید آرشیو را از فهرست مرورگر پاک کنید.

آرشیوها در پایگاه داده ذخیره نمی‌شوند و به همان مرورگر و پروفایل آن وابسته‌اند. پاک‌کردن داده‌های مرورگر ممکن است آرشیوهای ذخیره‌شده در آن را پاک کند؛ برای نگهداری مطمئن، از آن‌ها فایل JSON خروجی بگیرید.

## پرسش‌ها و مشکل‌های رایج

### پنجرهٔ برنامه باز نمی‌شود

مطمئن شوید Terminal هنوز باز است و `npm run dev` را اجرا کرده‌اید. اگر Terminal بسته شده، مراحل «هر بار که می‌خواهید برنامه را باز کنید» را دوباره انجام دهید.

### پیام می‌گوید `npm` شناخته نمی‌شود

Node.js نصب نیست یا پنجرهٔ Terminal پیش از نصب باز بوده است. Node.js LTS را نصب کنید، Terminal را ببندید و از نو باز کنید.

### پیام خطای نصب قطعات برنامه دیده می‌شود

برای `npm install` اتصال اینترنت لازم است. اینترنت را بررسی کنید و دستور را دوباره در پوشهٔ اصلی پروژه اجرا کنید.

### نماد تازه در فهرست نیست

مطمئن شوید پوشه داخل `public\data` است و حداقل یک CSV با نام تایم‌فریم پشتیبانی‌شده داخل آن قرار دارد؛ سپس صفحهٔ برنامه را Refresh کنید.

### فهرست نماد هست ولی چارت خالی است

فایل CSV ممکن است ستون‌های لازم را نداشته باشد، نام تایم‌فریم در نام فایل مشخص نباشد یا فرمت زمان قابل‌خواندن نباشد. نمونهٔ CSV و نام ستون‌های پشتیبانی‌شده در بخش «ستون‌های موردنیاز CSV» آمده است.

### برنامه روی نشانی دیگری اجرا شد

اگر `localhost:3000` قبلاً توسط برنامهٔ دیگری استفاده شود، Terminal ممکن است شماره‌ای مثل `3001` پیشنهاد دهد. همان نشانی‌ای را باز کنید که Terminal نمایش می‌دهد.

## یادآوری کوتاه برای استفادهٔ روزانه

۱. Terminal را از داخل پوشهٔ پروژه باز کنید.

۲. دستور زیر را اجرا کنید:

```powershell
npm run dev
```

۳. نشانی محلی نمایش‌داده‌شده را در مرورگر باز کنید.

۴. برای بستن برنامه، در Terminal کلیدهای **Ctrl + C** را فشار دهید.
